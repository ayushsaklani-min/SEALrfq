# Documentation

This directory contains implementation documentation for the three major layers of SealRFQ.

- [`frontend.md`](./frontend.md) describes the application structure, route flows, wallet interaction model, and frontend proxy layer.
- [`backend.md`](./backend.md) describes the API surface, authentication model, transaction tracking, database layer, and operational controls.
- [`program.md`](./program.md) describes the Leo program, privacy model, protocol phases, transition groups, and on-chain state.

Each document is written against the current repository structure and points back to the relevant source files.
